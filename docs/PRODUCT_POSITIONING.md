# MOVA · Product positioning revision (working brand)

**Product name (provisional): MOVA**  
Engineering repository remains `gep-agent-os`; binary names and public API paths remain unchanged. **No trademark, domain or legal clearance has been completed.**

## What changed

- From generic goals/productivity software to a **personal AI Agent** that knows your goals, organizes work, and aims to carry out approved tasks.
- Above-the-fold headline: “不只是 AI 助手。是替你行动的专属 Agent。”
- Agent-first conversational preview with the user goal: “我想在 3 个月内成为 AI Agent 工程师”.
- Structured plan, task status, consent boundary and next-step shown inside a realistic chat conversation rather than a project dashboard.
- Differentiation from generic LLM chat: long-term goal continuity, execution orchestration, evidence-based progress, user control.
- Three concrete scenarios: become an AI Agent engineer, rescue unfinished projects, coordinate everyday responsibilities.
- Concrete Github and release links, no fictitious testimonials or performance percentages.

## Truth in marketing

The website is explicitly labeled an **experimental product vision**.
The AI dialogue and mission status are illustrative. The live cloud SaaS and
fully autonomous task execution are not released. User downloads remain the
experimental Windows and Android companion builds, requiring a configured GEP
backend. The personal-agent runtime is an ongoing engineering objective.

## Name rationale

MOVA = movement, ongoing action and momentum; easy to pronounce and short.
This is a positioning **candidate**, not a final company/product trademark.
A legal clearance search in target jurisdictions and domain ownership review
must precede formal adoption and renaming installers / packages / public APIs.
